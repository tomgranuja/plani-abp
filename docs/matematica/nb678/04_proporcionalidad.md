## Proporcionalidad

> Objetivo: Comprender la proporcionalidad directa e inversa mediante tablas de valores.

- Saltos proporcionales (10 min.)
- Identificar proporciones (20 min.)
- Tablas de valores de proporciones (20 min.)
- Reflexión de aprendizaje (10 min.)

### Saltos proporcionales (10 min.)

Para mover el cuerpo, se seleccionan tres estudiantes para completar en pizarra contra el tiempo, cada uno una tabla de multiplicar. El curso y profesor tienen que saltar proporcionalmente a la cantidad de errores según la razón 1:3, es decir, por cada error (u omisión) se salta 3 veces.

[---> Ejemplo tablas de multiplicar](https://drive.google.com/uc?export=view&id=1gKVzCYKNn-5WTfs0D3jQcSQQQNBd7dAm)

### Identificar proporciones (20 min.)

Trabajan de manera individual con material recortable para pegar en el cuaderno de concepto y ejercitación:

- Representar razones
- Definición de proporción
- Identificar proporciones

[---> Material recortable](https://drive.google.com/uc?export=view&id=18Poo8I3WKTFBN95slNrg9b7w_BKxFq2X)

### Tablas de valores proporcionales (20 min.)

En grupos deben confeccionar tablas de valores proporcionales para dos situaciones, una de proporcionalidad directa y la otra de proporcionalidad inversa:

- Receta de pan amasado (harina y levadura)
- Tiempo de viaje para paseo (velocidad y tiempo)

Para ello, cada grupo recibe dos láminas con la información de cada situación. A partir de esto, elaboran en sus cuadernos las tablas de valores respectivas para cada situación:

| Harina, lev. 200[g] : 5[g], 4 personas  | Velocidad x tiempo 240[km] |
| --------------------------------------- | -------------------------- |
| 2 personas                              | 40 [km/h]                  |
| 8 personas                              | 60 [km/h]                  |
| 12 personas                             | 80 [km/h]                  |
| 20 personas                             | 120 [km/h]                 |

[---> Láminas de ejemplo](https://drive.google.com/uc?export=view&id=1iBjZlI2JLPUS9B6jy0X8Azv5ABV4QHab)

[---> Láminas de desafío grupal](https://drive.google.com/uc?export=view&id=1dWEG1FS61d_fz-4qLaEsW_0jqTo6f8jJ)

### Reflexión de aprendizajes (10 min.)

- Estrategias y dificultades para el trabajo grupal
- Patrones en cada tabla
- Relación de proporcionalidad directa e inversa
